# 사이거리

실제 장소를 검색·선택하고 두 좌표 사이의 **직선거리**를 계산하는 한국어 웹앱입니다. 도로 주행거리나 도보거리는 아닙니다. Nominatim은 좌표 검색에 사용하고, 거리 계산은 브라우저에서 Haversine 공식(평균 지구 반지름 6,371,008.8m)으로 처리합니다.

## 실행

Node.js 22 이상에서 `npm run dev` 후 http://localhost:3000 에 접속합니다. 의존성 설치가 필요 없습니다. 검증은 `npm test`로 실행합니다.

## GitHub → Vercel

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Vercel의 Add New → Project에서 저장소를 Import 합니다.
3. Root Directory는 이 파일들이 있는 디렉터리로 선택합니다. Framework Preset은 Other이며 `vercel.json`이 빌드 없이 정적 파일을 배포하도록 설정합니다.
4. 환경변수를 추가하지 않고 Deploy 합니다.

Redis, 데이터베이스, API 키, 환경변수가 필요 없습니다. `api/search.js`는 Vercel에서 자동으로 서버 함수가 되며, 로컬에서는 `server.js`가 같은 함수를 연결합니다. 검색을 서버에서 중계하므로 외부 API의 CORS 오류를 피하고 요청 제한 오류를 화면에 표시합니다. 아직 GitHub 업로드나 Vercel 배포를 수행하지 않은 소스 프로젝트입니다.

## 사용법

출발지와 도착지를 각각 입력하고 검색 버튼(또는 Enter)을 누른 뒤 검색 결과에서 장소를 선택합니다. 입력만 하고 선택하지 않은 장소로는 계산하지 않습니다. 두 장소를 선택하면 총거리와 그 하단의 **지도에서 보기** 링크가 표시됩니다. 링크는 OpenStreetMap에 두 좌표를 전달합니다. 지도에서 제안하는 경로의 거리는 앱의 직선거리와 다를 수 있습니다. 검색이 안 되면 시·구나 주소를 함께 입력하세요. OSM에 등록되지 않은 장소는 조회되지 않을 수 있습니다.

## 공개 Nominatim 이용 제한 — 배포 전 확인

사용자가 명시적으로 선택한 공개 API: https://nominatim.openstreetmap.org/search

[공식 이용 정책](https://operations.osmfoundation.org/policies/nominatim/)에 따라 자동완성을 구현하지 않았습니다. 검색은 버튼으로만 실행하며 결과를 브라우저에 24시간 캐시하고 검색 간 최소 1.1초를 둡니다. Web Locks 지원 브라우저에서는 같은 사이트의 여러 탭도 직렬화합니다. 브라우저가 식별용 Referer를 전송하도록 설정하고 OSM 출처를 화면에 표시합니다. 개인정보나 비밀 주소는 검색하지 마세요. 검색어는 외부 Nominatim에 전송되며 검색 결과는 이 브라우저의 localStorage에 저장됩니다.

**공개 서비스의 제한은 앱 전체 합산 초당 최대 1요청입니다.** 서버 런타임에서도 요청 간 최소 1.1초를 두고 최대 200개 결과를 24시간 메모리 캐시합니다. Vercel의 여러 인스턴스는 메모리를 공유하지 않으므로 Redis나 별도 공유 저장소 없이 전역 제한을 보장할 수 없습니다. 소규모 이용에서도 운영자가 합산 요청량을 관리해야 하며, 다중 사용자가 몰리는 공개 서비스로 확장할 때는 운영 전에 대체 검색 서비스 또는 전역 요청 제어가 필요합니다. 공개 API는 차단·장애가 발생할 수 있으며 운영 보장이 없습니다. 429 응답 시 최소 30초 동안 새 외부 요청을 제한하고 화면에 안내합니다. 한 번의 대기 후에도 제한이 지속되면 나중에 다시 이용해야 합니다.

검색 서비스 전환은 `config.json`의 `searchEndpoint`를 수정하면 됩니다. JavaScript 재작성 없이 변경할 수 있으며, 대체 서비스는 Nominatim 호환 응답과 브라우저 CORS 접근을 지원해야 합니다. 설정 파일만 변경한 뒤 재배포하세요. API 키가 필요한 유료 제공자로 전환할 때는 키를 공개 설정에 넣지 말고 별도 서버 구조를 사용해야 합니다.
